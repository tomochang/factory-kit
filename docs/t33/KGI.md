# T33 KGI

## KGI

- Metric: background runs (subagents the foreman starts with the Agent or Workflow tool) that either run past a hard cap with no recorded stop, or end with no cost-log row in their T report. Counted as a share of all background runs in the window.
- Target: 0 such runs, out of at least 20 background runs.
- Deadline: 14 days after the hooks are installed in the live foreman (his install step after the PRs). If install is on 2026-11-02, the deadline is 2026-11-16.
- How measured: `run-budget audit --since <install-date>` joins three sources: the cost log (`~/factory/.runs/runs.jsonl`), the subagent transcripts (`~/.claude/projects/-Users-<you>-factory/<session>/subagents/agent-*.jsonl`, de-duplicated by message.id) and the T reports the foreman sent (outbox / reply log). It lists every run whose transcript shows more tokens, tool uses or minutes than the hard cap with no stop row, and every finished run whose T report has no `Cost:` line. Target met when both lists are empty and there were 20 or more runs.
- Based on: Claude Code's own `maxTurns` cap was seen silently ignored: 72 turns with `maxTurns: 10` (`~/research/run-budget/sources/gh-claude-code-41143-maxturns-not-enforced.md:87`) and 6 turns with `maxTurns: 2` "exit normal" (`gh-claude-code-79303-maxturns-not-honored.md:61`). Its author: "Silent non-enforcement is worse than absence" (`:63`). Subagent usage seen by hooks was "100% zeros" over 381+ samples (`gh-claude-code-75979-subagentstop-usage.md:53`). The 20-run floor is an assumption (about one week of factory runs at this week's pace).
